# AI Usage - Homework 4

## AI Tool Used

I used ChatGPT as a learning tool to help me better understand Homework 4.

## How I Used AI

- I asked ChatGPT to explain the purpose of each tally function and how the functions work together.
- I used ChatGPT to better understand C structures, pointers, arrays, and opaque types.
- I asked questions about different parts of my code so I could understand what each section was doing.
- I used ChatGPT to help me understand how to test my functions and what the PASS and FAIL results meant.
- I asked for explanations of how a Makefile works and why commands like `make`, `make test`, and `make clean` are useful.
- I used ChatGPT to understand compiler errors and figure out what I needed to check or correct.
## AI Error or Limitation

One issue I experienced was that ChatGPT sometimes referred to the wrong line number when explaining where I should make a change. I had to check my code in VS Code to find the correct location before making changes.

## What I Learned

Using ChatGPT helped me better understand how to organize a C program into different files and how the tally functions work. I also learned more about testing my code, reading compiler errors, and understanding why opaque types are used. Asking questions throughout the assignment helped me become more familiar with the concepts instead of just focusing on getting the program to run.
