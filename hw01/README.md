# ECE 361 Homework 1

## Overview

This homework implements a small C library for number representation and bit manipulation. The library provides functions for printing binary values, extracting and replacing bit fields, and sign-extending two's complement values. It also includes a function for unpacking a 16-bit thermostat status word into its individual fields.

## Files

- `bits.h` - Function declarations for the bit-manipulation library.
- `bits.c` - Implementations of the bit-manipulation functions.
- `status.h` - Definition of the `status_t` structure and declaration of `status_unpack`.
- `status.c` - Implementation of the thermostat status-word decoder.
- `tests/test_bits.c` - Tests for the bit-manipulation functions and thermostat decoder.
- `Makefile` - Builds the library and test program.

## Building

To compile the project, run:

```bash
make
```

The project is compiled using C11 with the `-Wall` and `-Wextra` warning options.

To build and run all tests, run:

```bash
make test
```

To remove the files generated by the build, run:

```bash
make clean
```

## Bit-Manipulation Functions

### print_binary

`print_binary(uint32_t x, int width)` prints the lowest `width` bits of `x`, starting with the most significant bit. The bits are displayed in groups of four separated by spaces.

Valid width values are 1 through 32.

### get_field

`get_field(uint32_t word, int pos, int width)` extracts `width` bits beginning at bit position `pos` and shifts the result down to bit 0.

Valid arguments are:

- `width`: 1 through 32
- `pos`: 0 through 31
- `pos + width` must not exceed 32

For invalid arguments, `get_field` returns `0`.

A width of 32 is handled separately to avoid shifting a 32-bit value by 32 bits.

### set_field

`set_field(uint32_t word, int pos, int width, uint32_t value)` replaces a field in `word` with the lowest `width` bits of `value`. Bits outside of the selected field remain unchanged.

The same position and width restrictions used by `get_field` apply.

For invalid arguments, `set_field` returns the original `word` unchanged.

If `value` is wider than the selected field, only its lowest `width` bits are used.

A width of 32 is handled separately.

### sign_extend

`sign_extend(uint32_t value, int width)` interprets the lowest `width` bits of `value` as a two's-complement signed number and returns the result as an `int32_t`.

Valid width values are 1 through 32.

If `width` is outside this range, the function returns `0`.

A width of 32 is returned directly as an `int32_t` because no additional sign extension is necessary.

## Thermostat Status Word

`status_unpack(uint16_t word)` decodes the thermostat status word into a `status_t` structure containing:

- heater status
- compressor/cooling status
- fan status
- fault status
- mode
- reserved bit
- signed setpoint

The setpoint is stored in bits 15 through 8 as an 8-bit two's-complement value. `status_unpack` uses `get_field` to extract the fields and `sign_extend` to interpret the setpoint.

Valid thermostat modes are:

- 0 - OFF
- 1 - HEAT
- 2 - COOL
- 3 - AUTO
- 4 - FAN_ONLY

Mode values 5 through 7 are invalid. `status_unpack` preserves the raw mode value, so a returned mode greater than 4 indicates an invalid mode.

## Testing

The test program checks the bit-manipulation functions at important boundary conditions, including width 1, width 32, position 31, values that are too wide for a field, and negative two's-complement values.

The thermostat decoder is also tested with multiple status words, including the provided `0x1631` example.
